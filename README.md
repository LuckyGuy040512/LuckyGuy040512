## Featured projects

### [Hierarchical Sleeve-Regime Allocation](https://github.com/LuckyGuy040512/quant-research-toolkit/tree/main/projects/regime-aware-allocation)

Tests whether a global volatility HMM plus four sleeve-specific HMMs improve a
25-ETF constrained ERC allocation, finding better final-period risk-adjusted
performance but no statistically reliable after-cost return improvement over a
matched static control in walk-forward and robustness tests.

### [Multimodal Earnings Event Research](https://github.com/LuckyGuy040512/quant-research-toolkit/tree/main/projects/multimodal-earnings)

Tests the incremental value of SEC earnings text across 1,560 verified events
using point-in-time expectations, market controls, chronological validation, and
a FinBERT extension, finding no stable text increment sufficient for deployment.

### [Cross-Market Diagnostics of Short-Crowding Risk](https://github.com/LuckyGuy040512/quant-research-toolkit/tree/main/projects/crowded-shorts-risk)

Uses a 1.19-million-row point-in-time weekly panel, locked temporal tests, and
date-block inference to test securities-lending, options, and electronic-market
signals, finding that lending information dominated while the electronic-market
increment failed the economic deployment gate.

### [Quant Research Toolkit](https://github.com/LuckyGuy040512/quant-research-toolkit)

Demonstrates how forecasts translate into cost-aware portfolios through runnable
fictional-data experiments in factor testing, purged walk-forward ML, uncertainty
adjustment, and allocation, with visible failures and automated checks rather
than claims of live alpha.

## Research principles

1. Preserve point-in-time information and prevent look-ahead leakage.
2. Evaluate models on genuinely out-of-sample periods.
3. Make turnover, trading costs, and portfolio constraints explicit.
4. Prefer small, auditable components and reproducible outputs.
5. Protect confidential data, code, and alpha-generation logic.
